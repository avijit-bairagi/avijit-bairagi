# Avijit Bairagi — Portfolio

Personal website and engineering portfolio for **Avijit Bairagi**, Lead Software Engineer specializing in backend architecture, fintech platforms, and enterprise payment systems.

## Stack

- Vue 3 + TypeScript
- Vite
- Tailwind CSS

## Pages

- `/` — Home overview, digital products, and organizations worked with
- `/portfolio` — Career experience, projects, education, and skills
- `/contact` — Direct contact links

## Development

```bash
npm install
npm run dev
npm run build
npm run preview
```
